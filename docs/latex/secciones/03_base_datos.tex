\section{Modelo de Datos}

La base de datos está implementada en PostgreSQL administrado por Supabase. El esquema actual contiene \textbf{14 tablas} y cumple con la \textbf{Tercera Forma Normal (3FN)}. Sigue las siguientes convenciones:

\begin{itemize}
    \item Nombres de tablas en singular.
    \item Nombres de columnas en \texttt{snake\_case}.
    \item Clave primaria: \texttt{id} (UUID generado con \texttt{gen\_random\_uuid()}).
    \item Claves foráneas: \texttt{tabla\_id} (ej: \texttt{student\_id}, \texttt{level\_id}).
    \item Columnas de fecha/hora: \texttt{TIMESTAMPTZ}.
\end{itemize}

\section{Funciones SQL y reglas críticas}

El acceso del estudiante al ciclo de examen se realiza por las RPC \texttt{start\_exam}, \texttt{get\_exam\_attempt}, \texttt{save\_exam\_answer} y \texttt{submit\_exam}. \texttt{start\_exam} serializa la creación por estudiante, devuelve un intento en curso cuando existe y rechaza un nuevo intento si ya hay uno completado en la fecha de negocio CBA, calculada con \texttt{America/La\_Paz}. También exige que haya suficientes preguntas elegibles: cada una debe tener al menos dos opciones y exactamente una correcta.

La entrega calcula el porcentaje sobre los snapshots de preguntas y opciones, asigna el nivel desde \texttt{exam\_level\_snapshot} y marca el examen como completado. Los triggers impiden cambiar o eliminar snapshots, exámenes finalizados y respuestas de exámenes finalizados; la configuración vigente tampoco puede eliminarse.
